# 광운대 캠퍼스 도구 계획 (PC 전용)

기준일 2026-11-05. 이 문서가 현재 계획입니다. 다른 문서는 참고 자료입니다.
- `campus-roadmap.md`: 조사 보고서 (게시판 목록, 데이터 소스, 규정·법 검토)
- `aws-architecture.md`: 공개 영역 운영 설계 (학교 서버 예절, 보안, 운영 절차는 그대로 참고)
- `relay-design.md`: 암호화 캐시를 서버에 올리는 이전 설계. **PC 전용 + 브라우저 중계로 바뀌면서 캐시 업로드 부분은 쓰지 않습니다.** 연결 승인, 로그 규칙, 위협 분석은 참고합니다.

## 1. 목표와 원칙

**목표**: PC에서 Claude(데스크톱·웹)와 ChatGPT로 내 KLAS 정보와 학교 공개 정보를 합쳐서 묻고 답을 받습니다. 학교 공지는 Discord로 알림을 받습니다. 모바일은 범위 밖입니다.

**원칙**
- KLAS 비밀번호와 세션은 **내 PC 밖으로 나가지 않습니다.**
- KLAS 요청은 **항상 내 PC(브라우저나 kw-mcp)에서** 나갑니다. 서버는 KLAS에 접속하지 않습니다.
- 서버는 **개인 데이터를 저장하지 않습니다.** 답하는 동안만 메모리에 두고 버립니다.
- 읽기 전용입니다. 제출, 출석, 수강 같은 쓰기 기능은 없습니다.
- 학교 서버에는 목록 페이지만, 서버(IP)마다 간격을 두고 요청합니다. 막히면 멈춥니다.

## 4. 동작 흐름

**처음 한 번**
1. 확장을 설치하고 동의합니다.
2. (선택) 확장 설정에 학번·비밀번호를 넣고 "자동 재로그인"을 켭니다. 확장 안에 암호화해 보관하고 서버로 보내지 않습니다.
3. 확장의 [Claude에 연결] / [ChatGPT에 연결]을 누릅니다. 커넥터 URL이 복사되고 설정 페이지가 열립니다.
4. 붙여넣고 [추가]를 누르면 연결 창이 뜹니다. 확장의 [승인] 버튼을 누르면 연결 토큰이 Claude·ChatGPT에 저장됩니다.
5. (선택) Discord 초대 링크로 들어가 원하는 채널의 알림을 켭니다.

**쓸 때**
1. Claude·ChatGPT에서 질문하면 연결 토큰과 함께 AWS로 요청이 갑니다.
2. AWS가 내 브라우저의 확장에 일을 넘깁니다.
3. 확장이 로그인된 세션으로 KLAS에 요청합니다.
4. 결과가 AWS로 돌아오면 공개 정보와 합쳐 답하고, AWS는 바로 버립니다.

**만료될 때**
- **KLAS 세션 만료**: 자동 재로그인을 켰으면 확장이 백그라운드에서 다시 로그인하고 요청을 이어 갑니다. 꺼져 있으면 "KLAS 로그인 필요" 알림을 띄웁니다.
- **자동 재로그인을 멈추는 경우**: 로그인 실패 2회, 보안문자, 2차 인증, 임시 비밀번호. 이때는 직접 로그인하라고 알립니다.
- **연결 토큰 만료**: 갱신 토큰으로 자동 갱신합니다. 그것도 만료되면 연결 창이 다시 뜨고, 확장의 [승인]을 한 번 누릅니다.
- **세션 연장**: 세션을 일부러 늘리거나 주기적으로 로그인하지 않습니다.

## 5. 기능

**공개 도구**: 공지 검색과 최신 공지(분류별·학과별), 학식, 학사일정, 열람실 빈자리

**개인 도구**: 내 과목·시간표, 과제, 온라인강의, 퀴즈, 팀플, 과목 게시판 새 글

**합친 도구**

| 도구 | 합치는 것 |
|---|---|
| 이번 주 할 일 | 과제·강의·퀴즈·팀플 마감(제출한 것 제외) + 학사일정 |
| 오늘 브리핑 | 오늘 수업·강의실 + 오늘 마감 + 오늘 학식 + 새 공지 |
| 내 공지함 | 내 과목 게시판 + 내 학과 공지 + 학교 학사·장학 공지 |
| 휴강·보강·시험 찾기 | 과목 게시판 제목의 휴강·보강·시험 키워드 |
| 공강 활용 | 시간표 빈 시간 + 열람실 빈자리 + 학식 |

**알림**
- Discord 채널: 공개 공지만
- 확장 PC 알림: 개인 마감 ("데이터마이닝 과제 내일 12시 마감")

## 6. 어디에 무엇이 있나

| 데이터 | 위치 |
|---|---|
| KLAS 비밀번호 | 확장 안 (선택, 암호화) 또는 kw-mcp의 OS 키체인. 서버·Claude·ChatGPT에는 없음 |
| KLAS 세션 | 내 브라우저 |
| 개인 학사 데이터 | 물을 때 잠깐 AWS 메모리를 지나 Claude·ChatGPT로 감. 저장하지 않음 |
| 연결 토큰 | Claude·ChatGPT (우리 서버가 발급) |
| 연결 정보 | AWS: 무작위 사용자 ID, 브라우저 연결 ID (이름·학번 없음) |
| 공개 공지·학식·학사일정 | AWS 공개 DB |

## 7. AWS 구성 (서울, 멤버 계정 `kw-prod`)

**공개 쪽**
- 수집 Lambda (EventBridge 스케줄): 게시판별 파서, 서버(IP)별 최소 60초 간격, 하루 상한, 막히면 멈춤, 킬 스위치
- 공개 DB (DynamoDB): 공지, 학식, 학사일정
- 새 글 알림: DB 변경 이벤트 → 분배 Lambda → 채널별 큐(SQS) → Discord 전송 Lambda. 첫 수집은 알림 없이 기준점으로만 저장. 원문이 지워지면 메시지도 지움
- 검색: 공개 DB로 만든 SQLite 검색 파일을 S3에 둠
- 공개 MCP Lambda: 공개 도구

**연결 쪽**
- WebSocket API: 확장이 접속해 연결을 유지하는 통로
- 연결 테이블 (DynamoDB): 사용자 ID ↔ 브라우저 연결 ID
- 연결 승인 서버 (OAuth): 확장의 [승인] 버튼으로 연결을 끝냄
- 개인 MCP Lambda: 도구 호출이 오면 해당 브라우저에 일을 넘기고, 결과를 받아 공개 정보와 합쳐 답함. 결과를 넘겨받는 임시 항목은 요청마다 다른 키로 암호화하고 1분 안에 지움

**공통**: CDK(Python)로 구성, GitHub Actions(OIDC)로 배포, 함수마다 권한 분리(수집 함수는 연결 테이블을 못 읽음 등), 로그에 토큰·개인 데이터 남기지 않음, 알람은 이메일, 예산 알림

## 8. 만드는 순서

| 단계 | 만들 것 | 이 단계부터 되는 것 |
|---|---|---|
| 1 | AWS 기본 설정 + 메인 공지 수집 + Discord 채널 | 학교 공지 알림 |
| 2 | 공개 MCP (공지, 학식, 학사일정, 열람실) | Claude·ChatGPT에서 공개 정보 질문 |
| 3 | kw-mcp `.mcpb` 클릭 설치 + 합친 도구 + 퀴즈 | Claude 데스크톱에서 "이번 주 할 일", "오늘 브리핑" |
| 4 | 크롬 확장 (중계, 자동 재로그인, 연결 승인, PC 알림) + AWS 연결 쪽 | Claude 웹·ChatGPT에서 개인 기능 |
| 5 | 친구 학과 게시판 추가, 친구 초대 | 친구들도 사용 |

## 9. 먼저 확인할 기술 사항 (4단계 시작 전에 시험)

- 확장이 서버와 WebSocket 연결을 계속 유지할 수 있는지 (최신 크롬은 연결이 살아 있으면 백그라운드를 깨워 둠, 확인 필요)
- 확장이 KLAS 탭을 열지 않고도 로그인된 세션으로 요청할 수 있는지. 안 되면 화면에 띄우지 않는 KLAS 탭을 잠깐 열어 처리
- 확장의 백그라운드 로그인으로 만든 새 세션이 브라우저에 반영되는지
- ChatGPT 개발자 모드를 지원하는 플랜

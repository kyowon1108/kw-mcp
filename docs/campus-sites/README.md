## 먼저 알아야 할 보안 발견 (학교 정보보안팀에 알릴지 결정 필요)

1. **3dkiff.org**: 2022년에 xr.kw.ac.kr와 같은 인증서에 들어 있던 도메인이 지금은 도박 스팸 사이트입니다. 만료된 도메인을 남이 가져간 것으로 보입니다.
2. **python.kw.ac.kr**: 파일 목록이 공개돼 있고 `강의수료여부_open.zip`이라는 파일이 보입니다. 열거나 받지 않았습니다. 이름으로 보아 개인정보가 들어 있을 수 있습니다.

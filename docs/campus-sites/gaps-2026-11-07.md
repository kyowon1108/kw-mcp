# Sources KW CAMPUS still misses (2026-11-07)

Trigger: "광운대 총동문회 장학생 선발 어떻게 하지?" found nothing. The answer was on the 총동문회 gnuboard
(`dongmoon.kw.ac.kr`, http only), as a poster image plus hwp/pdf forms. This file lists every similar gap.

## Method

- Inventory first: `README.md`, `domains.json`, `boards.json`, `homepage-map.json`, `external.json` from this
  folder; collectors in `kw-campus/src/kwcampus/` (`deptboards.BOARDS`, `wwwboards`, `wixfeeds`, `aicon`);
  knowledge base `kw-mcp/src/kw_mcp/knowledge/faq.json` (345 entries) and `notice_links.json`.
- Coverage check against our own public API (`search_notices`), not school sites.
- New fetching: one GET per host, only where the inventory lacked the list page. UA
  `kw-campus-research (contact kyowon1108@gmail.com)`, 3.5 s apart, robots status from `domains.json`
  (all five are 404 = no rules). Hosts: `www.kwuaa.com` (notice list), `kw.happydorm.or.kr` (/60/6010.do),
  `www.kwu-studentcouncil.co.kr` (/notices), `kwalsc.kw.ac.kr` (/), `sdt.kw.ac.kr` (/). Five requests in total.
  A first try with Python urllib stopped at the TLS handshake on this Mac (no local CA bundle), so it sent no
  HTTP request. The curl retry verified every certificate.
- The dorm list endpoint comes from a public 2023 student scraper on GitHub (`kw-service/kw-notice-backend-dorm`),
  not from a second request to the dorm site.

### 1. 총동문회 notices: collect (a)

- **Source:** `https://www.kwuaa.com/bbs/board.php?bo_table=notice` ("공지/행사안내"). It is the same server
  (222.122.39.21) and the same board as `http://dongmoon.kw.ac.kr/bbs/board.php?bo_table=notice`.
- **Scheme:** **www.kwuaa.com serves https with a valid certificate** (curl verify OK, 200, 55 KB).
  dongmoon is http only (TLS alert). Use kwuaa.com, which removes the http-only problem. `deptboards` builds
  `https://` URLs, so it needs no http support.
- **robots:** 404 on both names.
- **Engine:** gnuboard with a custom div skin, not a table: `div.e_num`, `div.e_subject > a[href*=wr_id]`,
  `div.e_date` as `MM-DD` **with no year**. The year must be inferred from row order (wr_id descending).
  Writer, hits and date are in `div.m_view`.
- **Posting:** 16 rows on page 1, from 2025-07-16 to 2026-10-27, about one a month. The scholarship call is
  yearly in late August: wr_id 73 (2025-08-21) and wr_id 86 (2026-08-28). Results go out by SMS in
  late October and November.
- **Content:** the scholarship, election and 자랑스러운 광운인 posts carry downloads (`fa-download` on 4 of
  16 rows). The 2026 scholarship post is a poster image plus hwp/pdf forms, so poster and attachment
  extraction are required.
- **Other boards:** `news`, `Bulletin` (회보), `Recruit` (동문기업 채용정보), `alumni`, `LifeEvent`,
  `gallery`, `promotion`, `branch`, `qa`. `Recruit` is worth one GET next time. The other boards are not for
  students.
- **Questions it answers:**
  - 총동문회 장학 자격, 기간, 서류, 결과;
  - 총동문회비;
  - 동문 행사.
- **KB:** nothing. No entry mentions 총동문회 or 총동문회비.
- **Handling:**
  - (a) A new small gnuboard parser that can be reused for other gnuboard sites. Give it its own server gate.
    The daily budget is trivial at about one post a month.
  - (b) Add KB entries for "총동문회 장학 어떻게?" and "총동문회비 내야 해?", linking the board.
